# Backend Supabase

Sauvegarde et synchro des données locales, authentification, et fonctions qui gardent les clés d'API côté serveur. L'app fonctionne sans ce backend (local-first).

```
supabase/
├── migrations/   schéma Postgres, miroir du schéma SQLite
└── functions/    ex. proxy de l'API de recettes
```
